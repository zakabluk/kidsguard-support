Как работает приложение

  • Блокирует выбранные приложения (TikTok, YouTube, Roblox и т.д.) на устройстве ребёнка через системный Family Controls / ManagedSettings (Apple Screen Time API)
  • Определяет «дома ли ребёнок» по геозоне, домашнему Wi-Fi (BSSID роутера) и опционально BLE-маячку
  • Поддерживает несколько профилей мест (например, «Дом», «Школа») с разными правилами для каждого
  • Требует, чтобы ребёнок был в вашем Family Sharing — родитель подтверждает доступ к Экранному времени своим Apple ID

How it works

  • Blocks selected apps (TikTok, YouTube, Roblox, etc.) on the child's device using Apple's Family Controls / ManagedSettings (Screen Time API)
  • Detects whether the child is "home" using a geofence, the home Wi-Fi network (router BSSID), and optionally a BLE beacon
  • Supports multiple location profiles (e.g. "Home", "School") each with its own rules
  • Requires the child to be part of your Family Sharing group — the parent authorizes Screen Time access with their own Apple ID
